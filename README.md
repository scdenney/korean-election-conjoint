# Korean Election Conjoint Data

Replication data for the 2024 South Korea conjoint experiment on presidential candidate preferences.

## Files

- `final_df_direct.csv`: Cleaned data with direct responses only.
- `final_df_conjoint.csv`: Cleaned data including conjoint evaluation attributes.
- `data_dictionary_direct.csv`: Variable definitions for `final_df_direct`.
- `data_dictionary_conjoint.csv`: Variable definitions for `final_df_conjoint`.
- `README.md`: Overview and navigation aid (this file).

## DOI

 Denney, Steven. 2025. “Replication Data for: Partisan Voters in Party Systems with Ephemeral Parties: Evidence from South Korea.” Harvard Dataverse. https://doi.org/doi:10.7910/DVN/3N4UFF.
